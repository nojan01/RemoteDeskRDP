# Security Policy

Security fixes are provided for the latest published version of RemoteDeskRDP.

Please do not disclose a suspected vulnerability in a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/nojan01/RemoteDeskRDP/security/advisories/new)
and include the affected version, reproduction steps, impact and any relevant
logs with secrets removed.

RemoteDeskRDP stores passwords in the macOS Keychain. Diagnostic logs can still
contain host names, user names and remote-system details; review and redact them
before attaching them to any report.
